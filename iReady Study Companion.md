## 🎯 Overview

**i-Ready Browser Toolkit** is a curated collection of **browser extensions and utilities** designed to enhance the i-Ready learning experience. It focuses on **accessibility**, **readability**, **focus**, and **study support** — helping students, parents, and educators get more from the platform.

The toolkit is **not affiliated with Curriculum Associates** and does not modify, bypass, or interfere with i-Ready's lessons or assessments. Its goal is to make the interface more comfortable and accessible.

### 🎯 What It Solves

| Problem | Toolkit Solution |
|---------|------------------|
| 👁️ Small text | Zoom and font helpers |
| 📖 Reading difficulty | Text-to-speech tools |
| 🎯 Distractions | Focus mode |
| 🕐 Long sessions | Break reminders |
| 📊 Progress tracking | Dashboard helpers |
| ♿ Accessibility | High contrast, dyslexia fonts |
| 🎧 Audio issues | Volume normalization |
| 📝 Note-taking | Clipboard and notes tools |

## ⚖️ Ethical Use

> **🛑 Read This First**
>
> The i-Ready Browser Toolkit is intended **only** for legitimate accessibility, comfort, and study support. It is **NOT** designed to:
>
> - ❌ Bypass lessons, quizzes, or assessments
> - ❌ Automate answers or generate responses
> - ❌ Manipulate scores or progress
> - ❌ Circumvent teacher or school policies
> - ❌ Violate Curriculum Associates' Terms of Service
>
> **Permitted uses:**
> - ✅ Readability improvements
> - ✅ Text-to-speech and screen reader support
> - ✅ Focus and comfort features
> - ✅ Break reminders and time tracking
> - ✅ Note-taking and study aids
>
> **Always follow your school's acceptable use policy.**

## 🛠️ Extension Architecture

### 🧩 Structure

```
i-ready-toolkit/
├── manifest.json
├── background.js
├── content.js
├── popup/
│   ├── popup.html
│   └── popup.js
├── options/
│   ├── options.html
│   └── options.js
├── styles/
│   └── injected.css
└── assets/
    └── icons/
```

### 📄 Sample Manifest

```json
{
  "manifest_version": 3,
  "name": "i-Ready Toolkit",
  "version": "2.1.0",
  "permissions": ["storage", "activeTab"],
  "host_permissions": ["*://*.i-ready.com/*"],
  "background": { "service_worker": "background.js" },
  "content_scripts": [{
    "matches": ["*://*.i-ready.com/*"],
    "js": ["content.js"],
    "css": ["styles/injected.css"]
  }],
  "action": { "default_popup": "popup/popup.html" }
}
```

## 🩺 Troubleshooting

| Problem | Cause | Solution |
|---------|-------|----------|
| 🚫 Extension missing | Not installed | Reinstall |
| 🚫 TTS doesn't work | Audio blocked | Allow autoplay |
| 🚫 Font won't change | Site override | Enable in options |
| 🚫 Slow page | Too many extensions | Disable unused |
| 🚫 Theme reverts | Cache | Clear cache |
| 🚫 Profile lost | Sync off | Enable sync |
| 🚫 Timer wrong | Clock drift | Sync time |
| 🚫 Settings gone | Update reset | Reapply config |
| 🚫 Extension conflicts | Duplicate features | Keep one |
| 🚫 Not loading on i-Ready | Wrong URL | Refresh page |

### 🔄 Reset Extension

```
chrome://extensions → Details → Reset
```

## 💬 FAQ

**Is this affiliated with i-Ready?**
No — this is a community toolkit.

**Does it bypass lessons?**
No — it only improves accessibility and comfort.

**Is it allowed in schools?**
Check your school's acceptable use policy.

**Does it change my scores?**
Never — it doesn't interact with assessment logic.

**Is it free?**
Yes — open source and free.

**Does it work on mobile?**
Some extensions work on Kiwi browser; others don't.

**Will it slow my browser?**
Minimal impact with typical settings.

**Can I use a screen reader?**
Yes — designed to complement screen readers.

**How do I uninstall?**
Remove via your browser's extension manager.

**Are my notes saved locally?**
Yes — stored on your device.
